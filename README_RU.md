Telegram бот, который позволяет запускать заданные команды на выбранном хосте в домашней сети и возвращать результат их выполнения. Бот не устанавливает постоянное соединение с удаленным хостом, что позволяет выполнять команды асинхронно.

Бот предоставляет возможность не тратить время на настройку `VPN` сервера и деньги на внешний ip-адрес или `VPS` сервер для доступа к локальной сети, а также избавляет от необходимости использования сторонних приложений (`VPN` и `ssh` клиентов) на удаленном устройстве и не требует стабильного Интернет соединения.

## Дорожная карта

- [X] Выполнение команд на локальном (на котором запущен бот) или удаленном хосте (через `ssh`) в указанном интерпретаторе.
- [X] Поддержка параллельного (асинхронного) выполнения команд.
- [X] Менеджер `ssh` подключений с проверкой доступности хоста.
- [X] Поддержка навигации по каталогам.
- [X] Комбинированный доступ к удаленным хостам по ключу и/или паролю.
- [X] Обработка ошибок при использовании команд, которые требуют ввода от пользователя.
- [X] Поддержка хранения и повторного использования передаваемых переменных и фунций (команда `exit` очищает историю).

## Запуск

Вы можете загрузить предварительно скомпилированный исполняемый файл на странице [релизов](https://github.com/Lifailon/ssh-bot/releases) и запустить бота локально или в контейнере Docker, используя образ из [Docker Hub](https://hub.docker.com/r/lifailon/ssh-bot).

> [!NOTE]
> Перед запуском, необходимо создать своего Telegram бота, используя [@BotFather](https://telegram.me/BotFather) и получить его `API Token`, который необходимо указать в конфигурационном файле.

- Создайте рабочий каталог:

```shell
mkdir ssh-bot
cd ssh-bot
```

- Создайте и заполните `.env` файл внутри рабочего каталога:

```shell
TELEGRAM_BOT_TOKEN=XXXXXXXXXX:XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
TELEGRAM_USER_ID=7777777777

# Интерпретатор, используемый только при локальном запуске бота в Windows
# Доступные значения: powershell/pwsh
WIN_SHELL=pwsh
# Интерпретатор, используемый на локальных и удаленных хостах в Linux
# Доступные значения: sh/bash/zsh или другой
LINUX_SHELL=bash

# Параллельное (асинхронное) выполнение команд (по умолчанию: false)
PARALLEL_EXEC=true

# Глобальные параметры для ssh подключения (низкий приоритет)
SSH_PORT=2121
SSH_USER=lifailon
# Использовать пароль для подключения (опционально)
SSH_PASSWORD=
# Полный путь к закрытому ключу (по умолчанию: ~/.ssh/id_rsa)
SSH_PRIVATE_KEY_PATH=
# Сохранение и повторное использование передаваемых переменных и функций (по умолчанию: false)
SSH_SAVE_ENV=true
SSH_CONNECT_TIMEOUT=2
# Список хостов, разделенных запятой (имя пользователя и порт имеют повышенный приоритет)
SSH_HOST_LIST=root@192.168.3.102:22,root@192.168.3.103:22,192.168.3.105,192.168.3.106
```

> [!NOTE]
> Доступ к боту ограничен идентификатором пользователя. Вы можете узнать Telegram `id`, используя [@getmyid_bot](https://t.me/getmyid_bot) или в логах бота, при отправки ему сообщения.

- Запустите бота в контейнере:

```shell
docker run -d --name ssh-bot \
    -v ./.env:/ssh-bot/.env \
    -v $HOME/.ssh/id_rsa:/root/.ssh/id_rsa \
    --restart unless-stopped \
    lifailon/ssh-bot:latest
```

> [!NOTE]
> Окружение бота не хранится в образе, вместо этого используется механизм монтирования. Для доступа к удалённым хостам с помощью ключа необходимо пробросить файл закрытого ключа из хост-системы в контейнер (как в примере выше) и оставить содержимое переменной `SSH_PRIVATE_KEY_PATH` пустым.

## Сборка

```shell
git clone https://github.com/Lifailon/ssh-bot
cd ssh-bot
cp .env.example .env
docker-compose up -d --build
```
